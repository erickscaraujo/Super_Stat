# ⭐ Super Stat - Aventura Estatística

Desenvolvido por **Erick de S.C. Araújo**

## 🎮 Sobre o Jogo

Um jogo plataforma estilo Super Mario onde cada fase exige a resolução de uma **pergunta estatística** para progredir. Responda corretamente para avançar, ou erre e perca vidas!

## 🕹️ Gameplay

- **155 fases** temáticas, cada uma com uma pergunta estatística diferente
- Controles: **← →** para mover, **↑/Espaço** para pular
- Colete moedas (+50 pts) e derrote inimigos (+100 pts)
- Responda a perguntas sobre **média, mediana, moda e probabilidade**
- Diferentes níveis de dificuldade alteram o tempo e as vidas

## ⚙ Configuração

- **Dificuldade**: Fácil, Normal ou Difícil
- **Volume**: Música e efeitos sonoros
- **Controles**: Teclado (setas/espaço/enter/esc)
- **Salvar/Carregar**: Até 3 slots de save

## 💾 Sistema de Save

- Até 3 slots de salvamento
- Salva progresso, vidas, moedas e pontuação
- Recorde global armazenado no navegador

## 🎨 Recursos

- Canvas-based rendering com animações suaves
- Sistema de partículas para efeitos visuais
- Áudio procedural (Web Audio API)
- Tela de menu, configuração, pausa e Game Over
- 5 fases únicas com designs diferentes

## 🚀 Como Jogar

Abra o executável e divirta-se.

## 📋 Tecnologias

- HTML5 Canvas
- CSS3 (com Google Fonts)
- JavaScript vanilla
- Web Audio API para sons
- localStorage para saves
